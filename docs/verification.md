## ما لم يُتحقق منه على حساب مستخدم

لم تُستخدم مفاتيح API حقيقية أو تجريبية شخصية. فحص الرصيد والأوامر المفتوحة و`POST /order/test` اجتاز اختبارات محلية بمفاتيح وهمية فقط؛ يحتاج التحقق الشبكي لهذه الوظائف إلى إنشاء المستخدم مفاتيح Demo وحفظها في `.env` محلياً. لم يُنشأ أي أمر أو مركز.

## ملاحظات بيئة التشغيل

أمر Python النظامي يشير إلى WindowsApps وغير صالح؛ استُخدم Python المرفق بالتطبيق. قيود عزل Windows منعت الكتابة في مجلد الملفات المؤقتة والوصول الشبكي المباشر، لذا شُغّلت الاختبارات وفحوص Demo العامة خارج العزل بعد الموافقة. لا يحتاج المشروع حزم Python خارجية في المرحلة الأولى.

## بوابة المرحلة التالية

المرحلة الثانية تبني الاستراتيجية ومحرك backtesting فقط. لا تُضاف صلاحية تنفيذ حتى اكتمال إدارة المخاطر والمطابقة وKill Switch واختباراتها في المرحلة الثالثة. ML ولوحة التحكم مؤجلان وفق ترتيب المستخدم.
