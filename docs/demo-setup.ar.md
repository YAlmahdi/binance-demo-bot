# إعداد Demo خطوة بخطوة

لا تضع مفاتيح Binance في إعدادات Codex أو المحادثة. البرنامج المحلي هو الذي يقرأها داخلياً؛ تعليمات المشروع تمنع الوكيل والمهارات من فتح ملف الأسرار أو عرض قيمه.

## 1. الدخول إلى Demo أولاً

افتح [Binance Demo](https://demo.binance.com/) بنفسك وسجّل الدخول بحسابك المعتاد. لا تحوّل حسابك الحقيقي ولا تنقل إليه أموالاً. اختر Start Demo Trading إن ظهر، ثم USDⓈ-M Futures وتحقق من ظهور الرصيد الافتراضي. أهلية الوصول تختلف حسب الحساب والمنطقة. هذا مطابق لـ[دليل Binance الرسمي](https://www.binance.com/en/support/faq/detail/9be58f73e5e14338809e3b705b9687dd).

توقف هنا إن لم تتمكن من الدخول. لا تستخدم مفتاحاً حقيقياً أو endpoint حقيقياً كحل بديل. يمكنك إخبارنا بأسماء الأزرار أو نص الخطأ فقط دون بيانات حساسة.

## 2. إنشاء مفاتيح Demo

من داخل Demo افتح قائمة الحساب ثم API Management، أو [رابط إدارة مفاتيح Demo](https://demo.binance.com/en/my/settings/api-management). تحقق أن المضيف `demo.binance.com` ثم اختر Create API وسمّه `Futures-AI-Lab-Demo`.

عميل المشروع الحالي يدعم HMAC-SHA256 فقط؛ إذا عُرض اختيار النوع فاختر المفتاح المولّد من النظام HMAC. أكمل تحقق Binance بنفسك. نحتاج قراءة الحساب الآن فقط، ولا نطلب تفعيل صلاحيات تداول إضافية. إن اختلفت الخيارات صف أسماءها دون إظهار المفاتيح.

## 3. اختر مكان حفظ الأسرار قبل كتابتها

نُقل المشروع إلى C:\Users\yazan\Development\binance-demo-bot خارج OneDrive. استثناء `.env` من Git **لا يمنع مزامنته إلى OneDrive**. احفظ المفاتيح في النسخة المحلية الجديدة فقط ولا تُعد نسخ ملف الأسرار إلى OneDrive. نُقل المشروع بعد التحقق من الملفات والاختبارات، دون تغيير إعدادات المزامنة.

الأوامر التالية تفترض المسار الحالي؛ إذا اخترت مجلداً محلياً آخر فاستبدل المسار بموقع نسختك. لا تنشئ نسخة مفاتيح ثانية دون حاجة.

```powershell
cd "C:\Users\yazan\Development\binance-demo-bot"
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

اكتب بنفسك داخل Notepad، ثم احفظ وأغلق الملف:

```dotenv
BINANCE_ENV=demo
BINANCE_DEMO_API_KEY=YOUR_DEMO_API_KEY
BINANCE_DEMO_API_SECRET=YOUR_DEMO_API_SECRET
```

استبدل النصين الأخيرين بقيم Demo الحقيقية محلياً فقط، دون مسافات ضمن القيمة. لا تكتب المفاتيح في أوامر PowerShell لأن سجل الأوامر قد يحتفظ بها. لا تضعها في SKILL.md أو AGENTS.md أو README. لا تطبع `.env` لفحصه.

## 4. فحص القراءة بعد الإعداد

```powershell
$pythonExe = 'C:\Users\yazan\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $pythonExe run.py check-public
& $pythonExe run.py check-account
```

الأول يفحص الاتصال العام؛ الثاني يقرأ الرصيد والأوامر المفتوحة فقط. لا يفتح أو يلغي صفقات. إذا فشل، شارك فقط رسالة HTTP/code المنقحة؛ لا تشارك الأرصدة الكاملة أو مفاتيح أو headers أو توقيعات. متغيرات البيئة السابقة تتغلب على الملف؛ لا تطبع البيئة لتشخيص ذلك.

لم أنفّذ أي فحص حساب شخصي أو طلب أوامر أثناء إعداد المهارات. إعداد الحساب في متصفحك وحفظ مفاتيحه تبقى خطوات تنفذها أنت. لا ننتقل إلى test-order أو التنفيذ أثناء هذه الخطوات.
